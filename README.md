# CalDAV-Cal-API

Python library and command-line interface for interacting with CalDAV calendars (VEVENTs). Connect to a
CalDAV server, fetch calendars and events, and create, modify or delete events through simple Python
objects.

This is the calendar counterpart of [CalDAV-Tasks-API](https://github.com/thiswillbeyourgithub/CaldavTasksAPI/),
which covers tasks (VTODOs), and deliberately mirrors its architecture.
